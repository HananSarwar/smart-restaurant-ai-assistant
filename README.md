# 🍽️ Smart Restaurant AI Assistant

An AI-powered restaurant assistant built with **Node.js, LangChain, and Google Gemini**.  
The assistant can understand user queries and use custom tools to provide restaurant-related information such as daily menus.

---

## ✨ Features

- 🤖 AI-powered conversational restaurant assistant
- 🧠 Google Gemini LLM integration
- 🔗 LangChain agent architecture
- 🛠️ Custom menu tool using LangChain
- 🍳 Breakfast, lunch & dinner menu support
- 💬 Interactive chat interface
- ⚡ Fast backend powered by Node.js & Express
- 🎨 Modern and responsive restaurant UI
- 🔐 Environment variables for secure API key management

---

## 🧠 How It Works

The application follows an **AI Agent + Tool** architecture:

```text
User
  ↓
Chat Interface
  ↓
Node.js / Express Backend
  ↓
LangChain AI Agent
  ↓
Google Gemini
  ↓
Custom Restaurant Tool
  ↓
Restaurant Information
  ↓
AI Response
  ↓
